# Registra-gastos

A Python-based personal expense tracker developed incrementally as a learning project.

## About

Registra-gastos is a console-based application for recording and managing personal expenses.

The project is being developed incrementally, with each version introducing new functionality while reinforcing Python programming fundamentals and software development practices.

## Current version

**v1.4**

### Features

- Register expenses
- Predefined expense categories
- Expense descriptions with input validation
- COP value validation and formatting
- Automatic registration date
- Display registered expenses
- Calculate total expenses
- Input validation and error handling

## Technologies

- Python
- Git
- GitHub
